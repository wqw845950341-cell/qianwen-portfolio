# 巷遇｜旅行手账设计与交互规范

选定方向：第二套街巷手记；最终样式依据用户追加的“手绘 + 实拍风格”参考。视觉真值为 direction-02-refined.png，原方向稿保留作为探索过程。

## 基础样式

| 变量 | 值 | 用途 |
| --- | --- | --- |
| Ink | #244675 | 标题、主按钮、地图编号、图标 |
| Paper | #F7F8F4 | 页面及纸张背景 |
| Cornflower | #91AFE2 | 焦点、地图边界、轻量强调 |
| Butter | #F5D879 | 手账标记、演示状态 |
| Coral | #DF5C4F | 关键数字、选中点、起始编号 |
| Muted | #526987 | 辅助说明 |

正文采用系统中文无衬线，品牌英文与路线数字使用 Georgia。中文标题约 30–32px，正文 14–16px，辅助文字 12px；短英文装饰文案更小，但不承载必须依赖的信息。主按钮 50px 高，地图点及操作区域至少 44px。主按钮用色与文字保留足够对比；珊瑚色数字不独立承载选中状态。

页面横向内容留白 20px。主操作固定在底部，使用设备安全区；滚动内容预留底部空间，避免最后一个交互被遮挡。用户可切换 iPhone / Pixel 10 预览，设备外壳和模拟键盘是模板设施，不属于产品功能。

## 手绘与照片的分工

方格纸和建筑插画是独立栅格素材；照片使用 AI 生成的纪实摄影风格示意。照片边框可轻微旋转，正文、地图与按钮保持稳定对齐。标准图标使用 Radix Icons 的细线风格，不用表情字符代替功能图标。

地图底图和虚线路径为概念素材，交互编号由前端叠加。地图点、当前站点和详情共用同一地点 ID；这些素材不能用作真实导航路网。路线变更的距离与时序是演示规则结果，不能声称来自真实地图算路。

## 组件状态

- 偏好：默认、选中、聚焦、输入错误、生成中。兴趣最多三项，提交至少一项。
- 路线：默认、当前站点选中、行中、手动到达、跳过、结束；跳过不计为到达。
- AI：建议追问、文字输入、生成中、停止、资料不足、变更预览、取消、应用。
- 地图：摘要视图、展开视图、点位选择、全览、缩放、演示起点定位。
- 文化内容：摘要、展开、播放/暂停、语音不可用时文本回退、来源说明、错误反馈。
- 保存：空列表、已保存、恢复、删除；均仅当前设备。

## 明确的原型边界

本项目实现 H5 风格的前端交互，不是已经发布的小程序。没有登录、票务、支付、语音输入、实时天气、人流热度或后台轨迹采集。地图为示意；导航用地址复制回退；AI 为本地模拟；反馈保存在本机。

生产方案中的三挡地图抽屉、真实路径重算、来源检索系统、TTS 拖动定位、多轮模型对话、服务端指标等仍须进一步实现。原型未出现这些未接入能力的伪成功状态。
